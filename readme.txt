A minimalist block starter theme for WordPress.

== Description ==

Blanky is a minimalist block starter theme for WordPress. It is designed to be a clean, unstyled foundation for developers and designers who want to build their own custom block themes from scratch.

It provides the essential structure and files required for a block theme, including a basic `theme.json`, but leaves the styling and design decisions entirely up to you. Start your next block theme project with a truly blank canvas.

== Installation ==

This is a starter theme and is not intended for direct use on a production site without customization.

1.  In your WordPress admin panel, go to Appearance > Themes and click the 'Add New' button.
2.  Click 'Upload Theme' and choose the `blanky.zip` file.
3.  Click 'Install Now' and then 'Activate'.
4.  Alternatively, unzip the theme package and upload the `blanky` folder to your `wp-content/themes` directory.

== Getting Started ==

This is a starter theme, which means it's a starting point for your own theme development. After activating Blanky, you can begin customizing:

*   **Edit `theme.json`:** This is the core of your block theme. Define your global styles, settings, color palettes, typography, and more here.
*   **Modify Templates:** Edit the HTML files in the `templates` and `parts` directories using the Site Editor or your code editor to build your site structure.
*   **Add Patterns:** Create your own block patterns in the `patterns` directory to build reusable layouts.
*   **Add Custom CSS:** While most styling should be managed via `theme.json`, you can add any necessary custom CSS to `style.css`.
